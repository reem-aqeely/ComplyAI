# ComplyAI

منصة استشارية عربية (RTL) لتحليل امتثال الجهات الحكومية لضوابط هيئة الحكومة الرقمية (DGA) بمساعدة الذكاء الاصطناعي، مع مراجعة واعتماد بشري إلزامي (Human-in-the-Loop). نموذج أولي (POC) بواجهة أمامية فقط — بلا خادم، بلا قاعدة بيانات، بلا مصادقة.

## التشغيل

```bash
npm install
cp .env.example .env   # ثم أضف مفتاح GEMINI_API_KEY
npm run dev
```

احصل على مفتاح Gemini من [Google AI Studio](https://aistudio.google.com/apikey). ضَع المفتاح في `.env` **بدون علامات اقتباس أو مسافات زائدة** — فعلامة اقتباس واحدة زائدة تُصبح جزءاً من قيمة المفتاح وتُسبب الخطأ `400 API_KEY_INVALID`. أعد تشغيل الخادم بعد أي تعديل على `.env`.

بدون المفتاح، تعمل جميع أجزاء التطبيق عدا تحليل الذكاء الاصطناعي الفعلي، والذي يعرض رسالة توضيحية بدلاً من فشل صامت.

## البنية

```
src/
├── components/ui/     # مكوّنات تصميم أساسية (زر، بطاقة، جدول، لوحة جانبية...)
├── features/          # منطق كل ميزة (تحليل، لوحة التحكم، تقارير، المستشار، اللوائح، التدقيق)
├── pages/              # صفحات المسارات
├── layouts/            # هيكل التطبيق العام (شريط جانبي + رأس الصفحة)
├── services/
│   ├── knowledge-base/ # تحميل واستعلام ملفات ضوابط الأطر (JSON)
│   ├── gemini/         # بناء الطلب، الاتصال بـ Gemini، ومعالجة الاستجابة
│   ├── parser/          # استخراج نص PDF/DOCX داخل المتصفح
│   └── storage/         # مفاتيح localStorage
├── hooks/              # مخازن Zustand (الدور، التقييمات، تحديث اللوائح)
├── types/              # أنواع TypeScript المشتركة
└── data/               # dga_controls.json + بيانات الأطر الثابتة
```

## إضافة إطار جديد

محرك التحليل غير مرتبط بـ DGA تحديداً. لإضافة إطار جديد (PDPL، NCA ECC، ISO 27001، COBIT):

1. أضف ملف JSON بنفس شكل `src/data/dga_controls.json` (framework / meta / levels / flat_controls).
2. سجّله في `knowledgeBaseService` (`src/services/knowledge-base/knowledgeBaseService.ts`).
3. فعّل بطاقته في `src/data/frameworks.ts`.

لا حاجة لأي تعديل على واجهات التحليل أو التقارير أو سير العمل.

## ملاحظات تقنية

- **بلا خادم**: كل شيء يعمل داخل المتصفح؛ البيانات تُحفظ في `localStorage` فقط، ونداء Gemini يُنفَّذ من المتصفح مباشرةً عبر `src/services/gemini/geminiClient.ts`.
- **تنبيه أمني**: لأن النداء يتم من المتصفح، يُدمج مفتاح `GEMINI_API_KEY` داخل حزمة الواجهة ويمكن لأي زائر قراءته. هذا مقبول للتشغيل المحلي والنموذج الأولي فقط؛ قبل أي نشر عام قيِّد المفتاح من Google AI Studio أو انقل النداء إلى خادم وسيط.
- **HITL إلزامي**: نتائج الذكاء الاصطناعي استشارية فقط؛ لا يتغير حال أي ضابط دون قرار مستشار صريح (اعتماد/تعديل/رفض).
- **لا افتراء على الأدلة**: عند غياب الدليل يعيد النموذج النص الحرفي "لم يتم العثور على دليل يدعم هذا الضابط."
